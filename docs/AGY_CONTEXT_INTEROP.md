# Multi-Agent AI Collaboration & AGY Interop Specification
<!-- file: docs/AGY_CONTEXT_INTEROP.md -->

This document details the multi-agent AI workflow, context exchange architecture, and
inbox/outbox protocols used in `arduino26` to coordinate between CLI agents (AGY), Web UI models
(Gemini at gemini.google.com, ChatGPT), and IDE assistants (Jules, Copilot).

---

## 1. Directory Topography (`./agy/`)

```
arduino26/agy/
├── inbox/                  # Incoming prompts, user directives, and external LLM snippets
│   └── archive/            # Forensic immutable archive of ingested inbox files (chmod 444)
├── outbox/                 # Active turn status reports generated by agents
│   └── archive/            # Immutable archive of completed turn reports (chmod 444)
├── log/                    # Persistent conversation logs & serial execution telemetry
└── scratch/                # Overflow context bundles (> 250 KB safety limit)
```

---

## 2. Multi-Agent Collaboration Workflow

```
+---------------------------------------------------------------------------------+
|                              Gemini Web UI (Browser)                            |
|  - Architectural design, refactoring, code review                               |
+---------------------------------------------------------------------------------+
          ^ (Paste via clip2files)                       | (Copy via files2clip)
          |                                              v
+---------------------------------------------------------------------------------+
|                              System Clipboard                                   |
+---------------------------------------------------------------------------------+
          ^                                              |
          | (files2clip)                                 v (clip2files)
+---------------------------------------------------------------------------------+
|                              Arduino26 Workspace                                |
|  - AGY / Local Agents audit logs, run builds, update AI.md                      |
|  - Ingests directives from agy/inbox/, updates turn reports in agy/outbox/      |
+---------------------------------------------------------------------------------+
```

### Agent Roles & Guardrails

1. **AGY (CLI Tool):** Runs inside the terminal, executes build commands, updates project state,
   and logs diagnostic output into `agy/log/`.
2. **Gemini (Web UI - gemini.google.com):** Engaged via browser UI. Facilitates high-level code
   generation, refactoring, and strategy. Context exchange is routed via `files2clip` / `clip2files`.
3. **Jules (Google Async Agent):** Operates on isolated background tasks, generating PRs and
   storing branch state in `.jules/`.
4. **Copilot (IDE):** Real-time inline edits inside VS Code or Arduino IDE.

## 3. Context Packing & Unpacking Utilities

### Packing Context (`files2clip`)
To copy workspace files into the system clipboard formatted with cryptographic headers and
structured line boundaries:

```bash
# Pack specific sketches and directives
files2clip sketches/uno_blink AI.md

# Pack entire workspace (with 250 KB clipboard overflow protection)
files2clip -a
```

*Overflow Protection:* If the packed payload exceeds 250 KB, `files2clip` automatically writes
the bundle into `agy/scratch/bundle_YYYYMMDD_HHMMSS.txt` and copies a reference pointer to the clipboard.

### Unpacking Context (`clip2files`)
When receiving a multi-file response or patch from Gemini Web UI:

```bash
# Read clipboard payload and create/update workspace files
clip2files
```

### Stream Patching Shortcuts
```bash
# Pack output to clipboard via patch_io alias
pto sketches/uno_blink

# Unpack input from clipboard via patch_io alias
pti
```

## 4. Turn Reporting & Log Auditing

On every execution turn or milestone, AI agents MUST generate a turn status report under
`agy/outbox/` adhering to the following structure:

```markdown
# AGY Turn Status Report
- **Timestamp:** 2026-07-31T12:25:00-07:00
- **Agent:** AGY / Gemini 3.5 Flash
- **Target Component:** Arduino Uno CH340 Driver & Toolchain Setup
- **Status:** SUCCESS
- **Summary of Actions:**
  - Initialized git repository.
  - Sourced config_env and set up Python .venv.
  - Configured hardware scanner in tools/arduino_serial_bridge.py.
  - Flashed test sketch to /dev/ttyUSB0.
```

Turn reports are subsequently archived to `agy/outbox/archive/` and set read-only (`chmod 444`).
